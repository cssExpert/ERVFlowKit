# ERVFlowKit

**Build faster. Design smarter. Ship beautifully.**

ERVFlowKit is a modern, installable UI component and block library for React, Next.js, and Tailwind CSS. It provides production-ready components, marketing sections, dashboard blocks, layouts, templates, and developer tools that can be added directly into your project with a simple CLI command.

Unlike traditional UI libraries, ERVFlowKit gives you complete ownership of the code. Components are copied directly into your application, allowing unlimited customization without vendor lock-in.

## 📦 Installation

```bash
npx ervflowkit init
```

Add components directly into your project:

```bash
npx ervflowkit add button

npx ervflowkit add card

npx ervflowkit add hero-section

npx ervflowkit add pricing-section
```

Install multiple components at once:

```bash
npx ervflowkit add button card navbar hero-section
```
